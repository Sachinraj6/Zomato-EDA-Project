# Zomato EDA Project

## Objective
Analyze the Zomato restaurant dataset to discover patterns, trends and business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Findings
- New Delhi has the highest number of restaurants.
- North Indian cuisine is the most popular cuisine.
- Restaurants with online delivery have higher ratings.
- Higher-priced restaurants tend to receive better ratings.
- Price range shows a positive correlation with ratings.
